# 工作流资料

本目录按网站标签页归档每个页面使用的 ComfyUI 工作流文件与调用说明，方便备份、重新发布和核对节点映射。

所有说明均不包含 API Key。需要调用时，请在网页右上角或主创作台保存自己的密钥。

- `01-主创作台`：MJ 风格与街拍风格。
- `02-四视图角色卡`：角色卡生成。
- `03-MiniMax-H3-全能生图编辑`：单图/多图编辑工作流。
- `04-MiniMax-H3-一键消除`：画面元素消除工作流。
- `05-MiniMax-H3-视频生成`：文生视频、单图参考与多图参考。
- `06-图片裁剪`：浏览器本地工具，无 RunningHub 工作流。
- `07-模型调用器`：OpenAI 兼容模型配置工具，无 RunningHub 工作流。
- `08-Klein-换头`：Klein 面部融合工作流。

RunningHub 的返回链接通常仅保留 24 小时；网页会把可预览的图片与视频结果保存到当前浏览器的本地资源池。
